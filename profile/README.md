# scary-production

## Продукты

| Продукт | Что делает |
|---|---|
| **Сайт** | сотрудники по направлениям, свободное время по их сменам, онлайн-запись к сотруднику или сразу к направлению, перенос и отмена |
| **Вход** | код из SMS или письма, пароль, второй фактор для персонала; один вход на сайт, в кабинет и CRM |
| **Личный кабинет** | свои записи, несколько профилей на одну учётную запись, лист ожидания |
| **CRM** | расписание филиала: сотрудники, смены, записи; запись по звонку, поиск клиента по номеру |
| **Сотрудники** | карточки с фото, опытом и навыками, направления, рабочие контакты |
| **Клиенты** | клиенты и их профили, журнал просмотров данных клиента персоналом |
| **Напоминания** | SMS о записи, переносе и отмене; освободившееся время — первому в листе ожидания |
| **Уведомления** | SMS, письма и Telegram с запасными провайдерами |
| **Номенклатура** | услуги с внешними ID для связи с 1С и учётными системами |
| **Телефония** | в разработке: пропущенные звонки, расшифровка и разбор разговоров |
| **Чат с клиентами** | в разработке: переписка с клиентами на сайте и в мессенджерах |
| **Чат для сотрудников** | в разработке: переписка сотрудников между собой |
